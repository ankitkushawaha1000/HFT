# Old Mission Capital — Round 3: Technical Phone/Video Screen

**What this round assesses:** Live coding, C++ fundamentals, memory/data-structure understanding, and communication.

## Format

~45–60 minutes with one or two interviewers, mixing coding and C++ discussion. `anecdotal`

## Representative questions

1. Implement a stack that supports push, pop, and retrieving the minimum element in O(1). `anecdotal`
2. Given an integer array, return the indices of two numbers that add up to a target. `anecdotal`
3. What is the difference between heap and stack memory, and what is stack overflow? `anecdotal/general-prep`
4. Explain `unique_ptr`, `shared_ptr`, and `weak_ptr`, and when to use each. `anecdotal/general-prep`
5. How does `std::vector` reallocation work, and what is the amortized complexity? `anecdotal`
