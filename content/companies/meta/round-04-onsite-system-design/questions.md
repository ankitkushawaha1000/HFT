# Meta — Round 4: Onsite — System Design

**What this round assesses:** Distributed systems literacy, API design, storage choices, scalability patterns, realtime messaging, and consistency tradeoffs.

## Format

45-min virtual whiteboard/doc discussion: requirements, capacity, high-level design, DB schema/API, bottlenecks, tradeoffs.

## Representative questions

1. Design Instagram — photo storage, CDN, news feed fan-out, likes/comments. `anecdotal`
2. Design Facebook Messenger — realtime delivery, ordering, presence, group chats. `anecdotal`
3. Design a News Feed Ranking System — features, online scoring, A/B layer. `anecdotal`
4. Design Facebook Live — low-latency ingestion, adaptive bitrate streaming, viewer counts. `anecdotal`
5. Design WhatsApp — E2E encryption, durable queues, offline delivery. `anecdotal`
6. Design Facebook Ads Targeting — segmentation, real-time bidding, click tracking. `anecdotal`
7. For infrastructure roles, discuss memory-efficient data structures for 1B user IDs, zero-copy I/O, or protocol serialization. `inferred`
