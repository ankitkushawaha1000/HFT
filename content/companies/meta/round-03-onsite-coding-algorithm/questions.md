# Meta — Round 3: Onsite — Coding / Algorithm

**What this round assesses:** Algorithm depth, Big-O analysis, pressure handling, and clean code habits.

## Format

Two 45-min CoderPad rounds; each has 1–2 progressively harder problems with optimization follow-ups.

## Online assessment details

Platform: CoderPad live coding. Number/type: 1–2 problems per round. Topics: heaps, topological sort, linked lists, hash sets, DP, Union-Find, strings, segment tree/BIT. `official`
