# Amazon — Round 3: Onsite Loop — Coding / Algorithm

**What this round assesses:** Algorithmic correctness, complexity, C++ code quality, and LP evidence in each round.

## Format

1–2 virtual onsite rounds, 45–60 min each; same coding-plus-LP structure as the phone screen.

## Online assessment details

Platform: shared live coding environment. Number/type: 1–2 coding rounds, each also containing LP questions. Topics: caches, DP, heaps, MST, greedy, monotonic queues, tries, topological sort. `official`
