**What this round assesses:** Algorithm problem-solving and Leadership Principles behavioral depth.

## Format

45–60 min live video call using Amazon Chime plus shared code editor or CoderPad; every round includes coding and LP questions.

## Online assessment details

Platform: Amazon Chime + shared code editor or CoderPad. Number/type: 1 coding problem plus 2–3 LP behavioral questions. Topics: heaps, grids, top-K. `official`

4. Tell me about a time you took ownership of a project beyond your immediate responsibilities. `official`

6. Tell me about a time you had a conflict with a teammate about a technical approach. `official`
