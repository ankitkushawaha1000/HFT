# Amazon — Round 1: Online Assessment (OA) on HackerRank

**What this round assesses:** Baseline coding ability and Work Style Assessment alignment with Amazon Leadership Principles.

## Format

Asynchronous timed assessment sent by email; usually completed within a 5–7 day deadline window.

## Online assessment details

Platform: HackerRank. Number/type: 2 coding problems in 70–90 minutes plus a Work Style Assessment of ~110 forced-choice LP-related questions in a separate 15–20 min block. Representative topics: arrays, strings/log parsing, grids/graphs, intervals/heaps, simulation. `official`

## Representative questions

1. Array manipulation with sliding window or prefix sum, such as finding a subarray with sum exactly K. `anecdotal`
2. String parsing/counting, such as count badge access violations from a log. `anecdotal`
3. Tree or graph traversal, such as connected components in a warehouse grid. `anecdotal`
4. Greedy interval scheduling or heap-based ranking. `anecdotal`
5. Custom data-structure simulation, such as warehouse robotic routing. `anecdotal`
6. OA problems are often Amazon-themed but are standard CS problems underneath. `anecdotal`
