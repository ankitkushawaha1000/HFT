# Quadrature Capital — Round 3: Onsite in London

**What this round assesses:** Algorithms, C++/systems depth, math/statistics/probability, research intuition, and behavioral fit.

## Format

3–5 panels in one day, with reported coding, systems/C++, math/statistics/probability, and behavioral interviews. `anecdotal — medium confidence`

## Representative questions

1. Implement a function that finds the median of a stream as numbers arrive. `anecdotal`
2. Given a list of intervals, merge overlapping intervals and return the result. `anecdotal`
3. Explain the difference between `std::vector` and `std::list` in memory layout and iteration performance. `general-prep/inferred`
4. What is cache coherence, and how does it affect multi-core performance? `general-prep/inferred`
5. What is the expected number of dice rolls until seeing all six faces? `anecdotal`
6. You have a signal correlated with future returns; how would you test whether the correlation is statistically significant? `inferred`
7. Tell me about a technical project where you made a significant architectural decision and the tradeoffs involved. `general-prep/anecdotal`
