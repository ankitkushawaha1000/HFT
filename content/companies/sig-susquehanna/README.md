# SIG (Susquehanna International Group) — Interview Guide

Educational prep guide for publicly reported SIG technology and software engineering interviews.

## Snapshot

| Field | Details |
|---|---|
| Type | Global quantitative trading firm and market maker in options, equities, ETFs, and derivatives |
| HQ | Bala Cynwyd, Pennsylvania |
| Main offices | Chicago, New York, Dublin, London, Hong Kong, Sydney |
| Tech stack | C++, Python, Java, proprietary DSLs, FPGA |
| C++ usage | Options pricing engines, market-making systems, execution infrastructure, risk systems, volatility surface construction, order routing |
| Career page | https://sig.com/careers/ |

## Compensation (public estimates)

Public estimates are not offers and can vary by year, level, location, team, and bonus outcomes. Entry-level SWE estimates are about **$220K–$350K total compensation**. Senior estimates are about **$500K–$800K+ total compensation**, with bonus heavily tied to firm P&L and team performance.

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---:|---|
| Recruiter screen | 30 min | Background, SIG interest, C++ experience, logistics |
| Online assessment | 60–90 min | Algorithms, math/probability-flavored coding, domain simulation |
| Technical phone screen | 60 min | Live coding and C++ fundamentals |
| Superday | 5–6 hours | Algorithms, C++ systems, probability/EV, poker/trading games, behavioral fit |
