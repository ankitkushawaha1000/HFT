# SIG (Susquehanna International Group) — Round 3: Technical Phone Screen

**What this round assesses:** Live coding, data structures, C++ fundamentals, and problem decomposition.

## Format

60-minute live coding interview via CoderPad plus C++ fundamentals discussion.

## Representative questions

1. "Implement a binary search tree with insert, delete, and in-order traversal." `anecdotal`
2. "Given a matrix of 0s and 1s, count the number of connected components." `anecdotal`
3. "What are the most important new features in C++17? Give examples of when you'd use structured bindings and `if constexpr`." `anecdotal`
4. "Explain `std::optional<T>`. What problem does it solve? How is it implemented (is it zero-cost when empty)?" `anecdotal`
5. "What is the `noexcept` specifier? Why does it matter for move semantics?" `anecdotal`
6. "Write a function that flattens a nested JSON-like structure into a flat key-value map." `anecdotal`
7. "What is the difference between deep copy and shallow copy in C++? When does the default copy constructor perform a shallow copy?" `anecdotal`
