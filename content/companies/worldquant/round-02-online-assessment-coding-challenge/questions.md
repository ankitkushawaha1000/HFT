# WorldQuant — Round 2: Online Assessment / Coding Challenge

**What this round assesses:** Algorithmic problem-solving and, for some roles, quantitative/statistics reasoning.

## Format

Timed coding challenge; some reports describe coding plus math/quantitative reasoning.

## Online assessment details

Platform varies: HackerRank has been reported; some research-adjacent roles may use a proprietary WorldQuant assessment portal. Problems: 2–3 algorithmic problems, sometimes with a separate math/probability section. Difficulty: LeetCode medium.

## Representative questions

1. Find the number of islands in a 2D grid. `anecdotal`
2. Given daily returns, compute volatility and Sharpe ratio. `anecdotal`
3. For a biased coin with probability p of heads, find expected flips to get three consecutive heads. `anecdotal`
4. Implement a function that parses and evaluates a mathematical expression. `anecdotal`
