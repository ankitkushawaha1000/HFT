# Google — Interview Guide (C++ / Systems focus)

Google is a non-HFT high-comp employer with strong C++ usage in performance-sensitive systems, infrastructure, platforms, or product runtimes.

## Snapshot

| Field | Details |
|---|---|
| Type | Public (NASDAQ: GOOGL), Alphabet Inc. subsidiary |
| HQ | Mountain View, CA |
| Main offices | NYC, Seattle/Kirkland, Sunnyvale, Austin, San Francisco, Chicago, Boston; London, Zurich, Munich, Singapore, Tokyo |
| Tech stack | Chromium/Chrome, V8, Android NDK, TensorFlow core, Abseil, Protocol Buffers, gRPC, Bigtable, Spanner, Borg |
| C++ usage areas | Performance-critical backend infrastructure, Chrome/V8, Android/system libraries, TensorFlow runtime, storage/orchestration systems |
| Career page | https://careers.google.com/ |

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---|---|
| 1 | Recruiter / HR Screen | Phone or video call, 20–30 minutes, non-technical |
| 2 | Technical Phone Screen | OA/coding screen |
| 3 | Onsite — Coding / Algorithm Rounds | OA/coding screen |
| 4 | Onsite — System Design | Whiteboard-style virtual discussion, usually 45 min, for L4+; candidate leads requirements, scale, architecture, deep dives, and tradeoffs |
| 5 | Googleyness & Leadership Behavioral | Conversational 45-min video call with structured behavioral questions; no coding |
