# D.E. Shaw & Co. — Round 3: Technical Phone/Video Screen(s)

**What this round assesses:** Live coding ability, C++ depth, and communication under pressure.

## Format

Usually one or two video calls, each with one coding problem and several conceptual questions.

## Representative questions

1. Implement an LRU cache with O(1) operations using std::list and std::unordered_map. `anecdotal`
2. Given a BST, find the k-th smallest element. `anecdotal`
3. Serialize and deserialize a binary tree. `anecdotal`
4. Explain move semantics and rvalue references; why does std::move not actually move anything? `anecdotal`
5. Explain T&& in a template context vs a non-template context. `anecdotal`
6. What happens at the hardware level when accessing memory not in any CPU cache? `anecdotal`
7. Give examples of undefined behavior that corrupt runtime state. `anecdotal`
8. Expected flips to get two consecutive heads. `anecdotal`
9. Draw without replacement: probability of drawing 2 red before any blue from a 3 red / 7 blue bag. `anecdotal`
