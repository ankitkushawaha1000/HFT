# Two Sigma — Round 3: Technical Phone Screen

**What this round assesses:** Live coding, data structures, CS fundamentals, and ability to reason about complexity and trade-offs.

## Format

60-minute live coding interview via CoderPad with one interviewer. Usually 1–2 coding problems plus brief fundamentals discussion. Candidates report using Python or C++.

## Representative questions

1. "Implement an LRU Cache (get and put in O(1))." `anecdotal`
2. "Given a stream of numbers, find the median at any point in time." `anecdotal`
3. "Implement a thread-safe bounded queue in C++ (producer-consumer)." `anecdotal`
4. "Given a binary tree, serialize and deserialize it." `anecdotal`
5. "Design a function that computes a running percentile over a sliding window." `anecdotal`
6. "Explain the difference between `std::unique_ptr` and `std::shared_ptr`. When would you use each?" `anecdotal`
7. "What is the Big-O of your solution and can you optimize it?" `inferred`
