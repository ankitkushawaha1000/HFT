# Squarepoint Capital — Round 2: Technical Coding Assessment

**What this round assesses:** Basic algorithmic competence as an initial filter.

## Format

Timed online coding challenge; platform is not consistently reported.

## Online assessment details

Platform: reported as HackerRank by some candidates; others report a PDF take-home. Problems: 2–3 algorithmic problems. Difficulty: LeetCode medium-hard. Topics include data structures, graphs/trees, string/array manipulation, and mathematical reasoning.

## Representative questions

1. Implement a function to determine if a binary tree is a valid BST. `anecdotal`
2. Given a sequence of integers, find the longest palindromic subsequence. `anecdotal`
3. Given N nodes and K edges, find all connected components. `anecdotal`
