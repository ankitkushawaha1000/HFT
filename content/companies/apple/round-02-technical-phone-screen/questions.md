# Apple — Round 2: Technical Phone Screen

**What this round assesses:** Algorithmic fluency, C++ coding quality, and communication while coding.

## Format

1–2 video screens, 45–60 min each, using CoderPad, Codility, or plain Google Doc depending on team.

## Online assessment details

Platform: CoderPad, Codility, or Google Doc depending on team. Number/type: 1–2 algorithmic or C++ implementation problems. Topics: singleton, cache, iterators, producer-consumer queues, arrays. `anecdotal`

## Representative questions

1. Implement a thread-safe singleton in C++ using `std::call_once` and `std::once_flag`. `anecdotal`
2. Implement an LRU Cache. `anecdotal`
3. Flatten a nested list iterator. `anecdotal`
4. Design a simple bounded producer-consumer queue in C++. `anecdotal`
5. Find all pairs in an array with a given difference. `anecdotal`
