# Bloomberg — Interview Guide (C++ / Systems focus)

Bloomberg is a non-HFT high-comp employer with strong C++ usage in performance-sensitive systems, infrastructure, platforms, or product runtimes.

## Snapshot

| Field | Details |
|---|---|
| Type | Private limited partnership (Bloomberg L.P.) |
| HQ | New York City, NY |
| Main offices | London, San Francisco, Princeton, Hong Kong, Tokyo, Singapore, Frankfurt |
| Tech stack | Bloomberg Terminal, B-PIPE/BLPAPI C++ client library, tick data pipelines, market data distribution, order/risk systems, event-driven messaging |
| C++ usage areas | Terminal frontend/backend, real-time financial data, client APIs, execution/order systems, risk analytics, low-latency messaging |
| Career page | https://www.bloomberg.com/company/careers/engineering/ |

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---|---|
| 1 | Recruiter Screen | 20–30 min phone/video call |
| 2 | Technical Phone Screen | OA/coding screen |
| 3 | Onsite — Coding / Algorithm | 1–2 live CoderPad rounds, 45–60 min each; classic DSA often framed around financial data streams |
| 4 | Onsite — C++ Language Depth | 1–2 discussion-heavy rounds, 45–60 min each, sometimes with live coding of small snippets |
| 5 | Onsite — System / Software Design | 45–60 min whiteboard/virtual-doc design discussion with financial systems or realtime data framing |
| 6 | Behavioral / HR Round | 30–45 min conversational HR/behavioral round |
