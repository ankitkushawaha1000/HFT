## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---|---|
| 1. Online Assessment | 60–90 minutes | DSA correctness and efficiency; for some trading-technology tracks, speed arithmetic and probability. |
| 2. Technical Phone Screen | 45–60 minutes | Clean C++ implementation, core data structures, memory/value semantics, and basic options or trading interest. |
| 3. Technical Onsite / Virtual Day | 2–3 sessions, 45–60 minutes each | Deep C++17/20, concurrency, cache behaviour, low-latency systems, probability, EV reasoning, and options market-making intuition. |
| 4. Market-Making Simulation / Trading Game | 30–60 minutes | Real-time EV thinking, quoting discipline, inventory management, spread adjustment, and calm under adverse selection. |
| 5. Hiring Manager / Culture Fit | 30–45 minutes | Motivation for options market-making, resilience under pressure, ownership, and communication. |
