# G-Research — Round 2: Coding Test

**What this round assesses:** Algorithmic problem-solving, data structures, code correctness, and C++ or Python implementation ability.

## Format

Online coding assessment separate from the aptitude screen, usually medium-to-hard LeetCode level.

## Online assessment details

Platform: HackerRank or proprietary. Number/type: 2–4 algorithmic problems. Representative topics: caches, heaps, graph/topological processing, interval scheduling, and dynamic programming.

## Representative questions

1. Implement an LRU cache. Explain the data structure choice and complexity. `anecdotal`
2. Given a stream of integers, find the median after each insertion in O(log n). `anecdotal`
3. Topological sort or DAG shortest path `inferred`
4. Interval merging or scheduling problem `inferred`
5. Dynamic programming, such as minimum-cost path through a grid `inferred`
