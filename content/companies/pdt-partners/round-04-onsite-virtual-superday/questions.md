# PDT Partners — Round 4: Onsite / Virtual Superday

**What this round assesses:** Coding depth, quantitative/statistical reasoning, system design for experienced hires, research thinking, and behavioral fit.

## Format

About 4–6 hours of consecutive panels: multiple coding rounds, quantitative/statistical reasoning, system design, research discussion, and behavioral/culture. `anecdotal — medium confidence`

## Representative questions

1. Design and implement a system to efficiently find the top-k most frequent elements in a stream. `anecdotal`
2. Given a matrix of 0s and 1s, find the number of distinct islands. `anecdotal/general-prep`
3. What is a martingale? Give an example in finance. `anecdotal`
4. Describe the bias-variance tradeoff and how it appears in a statistical model. `inferred`
5. You run a regression and get R² = 0.95; should you trust it, and what would you check? `inferred`
6. What is the Kelly criterion, and how might it apply in a portfolio context? `anecdotal/inferred`
7. Design a real-time P&L system for 10,000 positions with prices updating at about 1M events/second. `inferred`
8. Design a backtesting framework for systematic equity strategies and discuss correctness concerns. `inferred`
9. How do you approach learning a new domain, such as options market microstructure? `inferred`
