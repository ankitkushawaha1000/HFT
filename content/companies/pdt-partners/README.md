# PDT Partners — Interview Guide

Educational interview-prep guide for software engineering, quantitative-development, and research-adjacent technical interviews at PDT Partners.

## Snapshot

| Field | Details |
|---|---|
| Type | Quantitative hedge fund; systematic trading across equities, futures, and macro `official` |
| HQ | New York, New York, USA `official` |
| Main offices | New York primary, London `official` |
| Tech stack | C++, Python `official`; Java mentioned historically `anecdotal`; Linux and distributed computing `inferred` |
| C++ usage | C++ appears in systems/execution role descriptions; engineers often work closely with quant researchers `official/inferred` |
| Career page | https://www.pdtpartners.com/careers.html |

## Compensation (public estimates)

Public estimates, not offers: Glassdoor, levels.fyi, and Blind suggest New York software engineer base salaries around $150–275k, with meaningful performance bonuses. Senior total compensation may reach roughly $300–500k+ in strong years, but data points are limited and hedge-fund compensation varies substantially. `anecdotal — medium confidence, sparse data`

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---:|---|
| 1. Recruiter/HR Screen | ~20–30 min | Background, motivation, fit |
| 2. Online Coding Assessment | ~60–90 min | Algorithms, coding, possibly statistics/math |
| 3. Technical Phone/Video Screen(s) | ~45–60 min each | Coding, probability/statistics, technical communication |
| 4. Onsite / Virtual Superday | ~4–6 hrs | Coding, quant reasoning, system design, research thinking, behavioral fit |
