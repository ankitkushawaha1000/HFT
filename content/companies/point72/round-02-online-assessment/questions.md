# Point72 Asset Management (incl. Cubist Systematic Strategies) — Round 2: Online Assessment (OA)

**What this round assesses:** Algorithmic problem-solving speed and correctness.

## Format

Timed unproctored coding challenge.

## Online assessment details

Platform: HackerRank or Codility (anecdotal). Problems: 2–3. Duration: ~90 minutes. Difficulty: LeetCode medium-hard. Topics include graphs, dynamic programming, heaps, and string parsing.

## Representative questions

1. Implement a function to find the kth most frequent element in an array. `anecdotal`
2. Given project dependencies, find a valid topological order or report a cycle. `anecdotal`
3. Find the minimum window substring containing all characters of a target string. `anecdotal`
4. Given buy/sell transactions and fees, maximize total profit. `anecdotal`
