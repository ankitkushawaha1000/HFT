# DRW — Interview Guide

Educational prep guide for publicly reported DRW software engineering interviews.

## Snapshot

| Field | Details |
|---|---|
| Type | Proprietary trading firm across equities, fixed income, crypto, commodities, FX, and other asset classes |
| HQ | Chicago, Illinois |
| Main offices | London, Amsterdam, Montreal, Singapore, New York |
| Tech stack | C++, Python, Java, OCaml, Rust, Go, Linux, FPGA work |
| C++ usage | Core trading infrastructure, order management systems, exchange connectivity, risk management, lock-free algorithms, Linux systems programming |
| Career page | https://drw.com/work-at-drw/ |

## Compensation (public estimates)

Public estimates are not offers and can vary by year, level, location, team, and bonus outcomes. Entry-level SWE estimates are about **$250K–$400K total compensation**. Senior estimates are about **$400K–$700K+ total compensation**, with year-end discretionary bonuses and limited transparency.

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---:|---|
| Recruiter screen | 30–45 min | Motivation, background, systems exposure, logistics |
| Technical phone screen 1 | 60 min | Algorithms, coding, trading-domain data problems |
| Technical phone screen 2 | 60 min | C++ and Linux systems knowledge |
| Onsite | 4–5 hours | Systems coding, C++ internals, trading infrastructure design, behavioral fit |
