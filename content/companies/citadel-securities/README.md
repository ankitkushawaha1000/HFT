# Citadel Securities — Interview Guide

Educational guide to Citadel Securities' reported software-engineering interview process for market-making and infrastructure roles.

## Snapshot

| Field | Details |
|---|---|
| Type | Market maker across equities, options, fixed income, FX, and other asset classes |
| HQ | Miami, Florida, USA |
| Main offices | Miami, Chicago, New York, London, Hong Kong |
| Tech stack | C++, Python, distributed systems tooling |
| C++ usage | Explicitly listed in official market-making and infrastructure job descriptions; central for performance-sensitive trading systems. |
| Career page | https://www.citadelsecurities.com/careers/ |

## Compensation (public estimates)

These are public estimates from sources such as Glassdoor, levels.fyi, and Blind, not offers or official ranges.

| Level | Public estimate |
|---|---|
| Entry | Entry-level SWE reported around $150K–$200K base plus $80K–$150K first-year/sign-on bonus. |
| Senior | Senior/staff roles reported around $200K–$300K+ base plus $150K–$400K+ bonus; senior TC frequently reported at $400K–$600K+, with some top IC reports around $700K+. |

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---:|---|
| Recruiter screen | 20–30 min | Background, motivation, level calibration, compensation alignment, and logistics. |
| Online Assessment | 60–90 min | Timed algorithmic coding, data structures, algorithms, and sometimes systems-awareness. |
| Technical phone screen(s) | 1–2 rounds, 45–60 min each | Live coding, C++ depth, systems reasoning, and performance tradeoffs. |
| Superday / Final Onsite | 4–6 interviews in one day, sometimes split | Algorithms, C++/systems depth, system design, and behavioral/fit. |
