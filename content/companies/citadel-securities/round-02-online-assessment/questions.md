# Citadel Securities — Round 2: Online Assessment

**What this round assesses:** Algorithmic coding under timed conditions, with emphasis on data structures, algorithms, and sometimes light system-design awareness.

## Format

Timed coding assessment, commonly reported as 60–90 minutes.

## Online assessment details

- **Platform:** HackerRank or CodeSignal are most commonly reported.
- **Number/type of problems:** Typically 2–3 algorithmic problems of medium to hard LeetCode-equivalent difficulty.
- **Representative OA topics:** Graph problems, dynamic programming, data structure design, array/string algorithms with complexity constraints, and occasionally a systems-awareness question such as memory-layout reasoning.

## Representative questions

1. Graph problems such as shortest path or BFS/DFS variants. `[anecdotal]`
2. Dynamic programming problems such as interval scheduling or knapsack variants. `[anecdotal]`
3. Data structure design such as implementing a cache or order book component. `[anecdotal]`
4. Array/string algorithms with complexity constraints. `[anecdotal]`
5. Memory layout reasoning as a systems-awareness prompt. `[anecdotal]`
