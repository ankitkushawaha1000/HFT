# PDT Partners — Round 3: Technical Phone/Video Screens

**What this round assesses:** Coding, probability/statistics, data structures, and concise technical explanation.

## Format

One or two technical video calls covering coding and quant/probability questions. `anecdotal`

## Representative questions

1. Implement an LRU cache and explain the data structures used. `anecdotal`
2. Given a binary tree, determine whether it is a valid BST. `anecdotal/general-prep`
3. What is the expected number of coin flips to get heads-heads? `anecdotal`
4. For correlated standard normal variables X and Y with correlation rho, what is `Var(X + Y)`? `general-prep`
5. Describe how a hash map handles resizing and the amortized cost of insert. `general-prep`
