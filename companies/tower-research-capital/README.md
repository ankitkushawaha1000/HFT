# Tower Research Capital — Interview Guide

Educational prep guide for publicly reported Tower Research Capital software engineering interviews.

## Snapshot

| Field | Details |
|---|---|
| Type | Quantitative HFT / proprietary trading firm with extreme latency focus |
| HQ | New York City |
| Main offices | Chicago, London, Singapore, Amsterdam |
| Tech stack | C++, Python, assembly-level optimization, SSE/AVX intrinsics, FPGA, Linux, kernel bypass, DPDK, co-location infrastructure |
| C++ usage | Mission-critical trading systems, market-data handling, order routing, cache/branch/NUMA-aware performance engineering |
| Career page | https://www.tower-research.com/open-positions |

## Compensation (public estimates)

Public estimates are not offers and can vary by year, level, location, team, and bonus outcomes. Entry-level SWE estimates are about **$200K–$350K total compensation**. Senior estimates are about **$400K–$700K+ total compensation**, with sparse public data and heavily bonus-driven outcomes.

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---:|---|
| Recruiter screen | 30 min | C++ background, low-latency experience, motivation, logistics |
| Technical phone screen | 60 min | Live coding, C++ knowledge, performance reasoning |
| Onsite | 4–5 hours | Algorithms, extreme C++ performance, low-latency systems design, probability/math |
