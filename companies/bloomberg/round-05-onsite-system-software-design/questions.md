# Bloomberg — Round 5: Onsite — System / Software Design

**What this round assesses:** Software architecture, data modeling, real-time systems, fault tolerance, and latency considerations.

## Format

45–60 min whiteboard/virtual-doc design discussion with financial systems or realtime data framing.

## Representative questions

1. Design a real-time market data feed handler for multicast tick data normalization and sub-millisecond subscriber distribution. `anecdotal`
2. Design a simplified Bloomberg Terminal delivering real-time prices for 10M securities to 320k users globally. `anecdotal`
3. Design an order book system for an exchange: bids/asks, matching engine, market depth queries. `anecdotal`
4. Design a pub/sub messaging system for financial events: durability, ordering, at-least-once vs. exactly-once. `anecdotal`
5. Design a financial time-series database for tick ingestion, OHLCV aggregation, and efficient range queries. `anecdotal`
