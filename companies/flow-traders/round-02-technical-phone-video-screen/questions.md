# Flow Traders — Round 2: Technical Phone/Video Screen

**What this round assesses:** Live coding ability, C++ fundamentals, basic systems knowledge, and communication under pressure.

## Format

~45–60 minutes with one interviewer, mixing shared-editor coding with C++ and systems discussion. `anecdotal`

## Representative questions

1. Write a function to find the kth-largest element in an unsorted array. `anecdotal`
2. What is the difference between `std::unique_ptr` and `std::shared_ptr`, and when would you choose each? `anecdotal/general-prep`
3. Explain how a hash map is implemented and what happens on hash collision. `anecdotal/general-prep`
4. What is the difference between stack and heap memory, and which is faster? `anecdotal`
5. Describe RAII and give a concrete example. `inferred`
