# Flow Traders — Round 3: Onsite / Virtual Onsite

**What this round assesses:** Full-stack depth: algorithmic correctness, C++ production judgment, systems reasoning, trading intuition, and culture fit.

## Format

3–5 panels in one day, commonly reported as coding/algorithms, C++ and systems, probability/trading intuition, and behavioral/culture. `anecdotal`

## Representative questions

1. Given a stream of integers, implement a data structure that supports efficient insert and median retrieval. `anecdotal`
2. Implement a rate limiter using a sliding window. `anecdotal/general-prep`
3. Explain move semantics in C++11 and when they are triggered. `inferred`
4. What is false sharing, and how would you diagnose and fix it in a multithreaded application? `inferred`
5. Describe the lifecycle of a network packet from NIC to userspace in Linux. `inferred`
6. You have a biased coin with probability p of heads; generate a fair 50/50 outcome. `anecdotal`
7. As an ETF market maker, how would you think about pricing the spread for a basket with three components? `inferred`
8. Tell me about a time you debugged a production system under time pressure. `anecdotal/general-prep`
