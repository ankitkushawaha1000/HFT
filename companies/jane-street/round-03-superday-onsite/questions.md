# Jane Street — Round 3: Superday / Onsite

**What this round assesses:** Coding, system design, behavioral fit, collaborative problem solving, abstraction, decomposition, and reasoning out loud.

## Format

Full day of interviews, possibly virtual. Typically includes 2–3 coding rounds, 1 system design round, and 1 behavioral/fit round.

## Representative questions

1. Implement a segment tree, or explain when you'd use one vs a BIT/Fenwick tree. `[anecdotal]`
2. Write a parser for a simple arithmetic expression with operator precedence. `[anecdotal]`
3. Implement a function that, given a sorted array and a target, returns indices of two numbers that sum to target, with follow-ups. `[anecdotal]`
4. Design and implement an LRU/LFU cache. `[anecdotal]`
5. How does the C++ memory model's acquire/release ordering work? Write a correct SPSC queue. `[inferred]`
6. What are the correctness risks with `std::string_view`, `std::span`, and references? `[inferred]`
7. Explain NUMA, false sharing, and how you'd structure a multi-threaded feed-processing pipeline. `[inferred]`
8. Design an in-memory limit order book for top-of-book and full depth. `[inferred]`
9. Design a market-data feed handler with gap recovery. `[inferred]`
10. Design a distributed key-value store, or a pub/sub message bus for strategies. `[anecdotal]`
11. Tell me about a system you're proud of — walk me through the key design decisions. `[anecdotal]`
12. Describe a time you and a colleague disagreed on a technical approach. How did it resolve? `[anecdotal]`
13. How do you approach learning a new codebase or domain quickly? `[anecdotal]`
