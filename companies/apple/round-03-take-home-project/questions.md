# Apple — Round 3: Take-Home Project

**What this round assesses:** Real-world C++ coding practices, design choices, correctness, performance awareness, and testing habits.

## Format

Optional/team-dependent project after phone screen; usually 1–7 days and 200–500 lines of C++ implementing a small system or library.

## Online assessment details

Platform: take-home project rather than a standard OA; some teams use this instead of an async platform. Number/type: one mini-system/library in C++. Topics: allocators, thread pools, parsers, caches, vector internals. `anecdotal`

## Representative questions

1. Implement a memory allocator supporting malloc/free with a buddy system or slab allocator. `anecdotal`
2. Implement a C++ thread pool with task queue and configurable concurrency. `anecdotal`
3. Write a basic JSON parser in C++ with error handling and streaming support. `anecdotal`
4. Implement a generic LRU cache with O(1) get and O(1) put using modern C++17. `anecdotal`
5. Implement a simplified `std::vector` with move semantics, exception safety, and allocator interface. `anecdotal`
