# D.E. Shaw & Co. — Round 5: Superday — Coding Round 2

**What this round assesses:** Algorithmic depth and ability to manage multiple constraints.

## Format

Second live coding round, often harder or more systems-flavoured.

## Representative questions

1. Implement a bounded thread-safe producer-consumer queue in C++ with mutex and condition_variable. `anecdotal`
2. Search a target in a sorted matrix where each row and column is sorted. `anecdotal`
3. Evaluate a mathematical expression string with operators and parentheses. `anecdotal`
4. Design a time-series data structure supporting push, range query, and getMax in O(log n). `anecdotal`
5. Count ways to climb N stairs with steps of 1, 2, or 3. `anecdotal`
6. Given order dependencies, detect cycles and return a valid build order. `anecdotal`
