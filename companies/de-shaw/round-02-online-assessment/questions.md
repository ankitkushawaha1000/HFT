# D.E. Shaw & Co. — Round 2: Online Assessment (OA)

**What this round assesses:** Algorithmic problem-solving efficiency and correctness.

## Format

Timed HackerRank coding challenge with no human interviewer.

## Online assessment details

Platform: HackerRank, widely reported. Problems: 2–3. Duration: ~90 minutes. Difficulty: LeetCode medium to hard. Topics include DP, graphs, strings, binary search, and data-structure design.

## Representative questions

1. Maximum profit with at most K buy-sell stock transactions. `anecdotal`
2. Minimum number of coins to make change for a target amount. `anecdotal`
3. Longest common subsequence of two strings. `anecdotal`
4. Word break: determine whether a string can be segmented into dictionary words. `anecdotal`
5. Count islands in a 2D grid using BFS/DFS. `anecdotal`
6. Implement a stack supporting push, pop, and getMin in O(1). `anecdotal`
