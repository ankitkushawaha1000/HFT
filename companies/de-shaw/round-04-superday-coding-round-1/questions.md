# D.E. Shaw & Co. — Round 4: Superday — Coding Round 1

**What this round assesses:** Algorithmic thinking, clean C++ code, edge cases, and complexity.

## Format

Live coding in a shared editor with one medium-hard problem and extensions.

## Representative questions

1. Find all permutations of a string with duplicate characters while avoiding duplicate outputs. `anecdotal`
2. Implement a deep copy of a linked list where each node has a random pointer. `anecdotal`
3. Given an array, return all triplets that sum to zero. `anecdotal`
4. Implement an iterator over a 2D vector, skipping empty rows. `anecdotal`
5. Design a data structure to track the most recently accessed N elements in insertion order. `anecdotal`
6. Solve minimum window substring. `anecdotal`
7. Compute trapped rain water. `anecdotal`
