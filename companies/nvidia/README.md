# NVIDIA — Interview Guide (C++ / Systems focus)

NVIDIA is a non-HFT high-comp employer with strong C++ usage in performance-sensitive systems, infrastructure, platforms, or product runtimes.

## Snapshot

| Field | Details |
|---|---|
| Type | Public (NASDAQ: NVDA) |
| HQ | Santa Clara, CA |
| Main offices | Austin, Seattle, Westford, Durham, Santa Clara; Taipei, Singapore, Munich, Tel Aviv, Cambridge |
| Tech stack | CUDA C/C++, cuBLAS, cuDNN, cuSPARSE, TensorRT, Triton, NCCL, DRIVE, Omniverse, OptiX, PhysX, GPU drivers, Mellanox networking |
| C++ usage areas | CUDA/GPU programming, math libraries, inference/runtime systems, drivers, autonomous vehicle stack, simulation, networking |
| Career page | https://www.nvidia.com/en-us/about-nvidia/careers/ |

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---|---|
| 1 | Recruiter Screen | 20–30 min call covering background, relocation/visa, team fit, and C++/parallel-programming exposure |
| 2 | Technical Phone Screen | OA/coding screen |
| 3 | Onsite — Coding / Algorithms | OA/coding screen |
| 4 | Onsite — CUDA / GPU Architecture Depth | 1–2 whiteboard/doc or coding rounds, 45–60 min each; may require CUDA code, pseudocode, or architecture discussion |
| 5 | Onsite — System / Software Design | 45–60 min virtual whiteboard discussion, often focused on GPU/ML systems rather than generic web-scale systems |
| 6 | Hiring Manager / Behavioral Round | Conversational 45-min call with background discussion and past-project deep dives |
