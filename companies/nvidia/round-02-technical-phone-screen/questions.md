# NVIDIA — Round 2: Technical Phone Screen

**What this round assesses:** Baseline algorithm proficiency, C++ fluency, and domain awareness.

## Format

1–2 video sessions of 45–60 min in CoderPad or HackerRank; usually 1 coding problem plus C++ questions.

## Online assessment details

Platform: CoderPad or HackerRank. Number/type: one coding problem plus C++ language questions. Representative topics: concurrency, arrays/lists, move semantics, smart pointers, nested structures. `anecdotal`

## Representative questions

1. Implement a thread-safe bounded queue in C++ using `std::mutex` and `std::condition_variable`. `anecdotal`
2. Array or linked-list manipulation problem at medium LeetCode difficulty. `anecdotal`
3. Explain `std::move` vs. `std::forward` with a concrete example. `anecdotal`
4. What are the differences between `std::unique_ptr`, `std::shared_ptr`, and `std::weak_ptr`? `anecdotal`
5. Write a function to flatten a nested data structure. `anecdotal`
