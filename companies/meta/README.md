## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---|---|
| 1 | Recruiter Screen | 30 min phone/video; non-technical, with product/team interest and relocation discussion |
| 2 | Coding Screen | OA/coding screen |
| 3 | Onsite — Coding / Algorithm | OA/coding screen |
| 4 | Onsite — System Design | 45-min virtual whiteboard/doc discussion: requirements, capacity, high-level design, DB schema/API, bottlenecks, tradeoffs |
| 5 | Behavioral / Jedi Round | Conversational 45-min values round using STAR-format responses; no coding |
