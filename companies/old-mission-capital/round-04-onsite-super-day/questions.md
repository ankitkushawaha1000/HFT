# Old Mission Capital — Round 4: Onsite Super Day

**What this round assesses:** Coding, C++ depth, systems design, probability market-making, adaptive reasoning, and behavioral fit.

## Format

Full-day onsite or virtual loop with 4–6 panels: coding, C++ depth, systems design, trading/probability game, and behavioral. `anecdotal — medium-high confidence for structure`

## Representative questions

1. Design an efficient data structure for a last-N-elements rolling average and discuss tradeoffs if N is very large. `anecdotal`
2. Given a stream of prices, return the running median after each new price. `anecdotal`
3. Implement a hash map from scratch in C++ and handle collisions. `anecdotal`
4. Explain the Rule of Five in C++ and write a class that implements it correctly. `anecdotal/general-prep`
5. What is undefined behavior in C++? Give three production-relevant examples. `anecdotal`
6. Design a low-latency order book supporting add, cancel, modify, and best-bid-ask query under a sub-microsecond target. `inferred`
7. Roll two dice; I tell you the sum but not individual values. Make me a market on the higher die. `anecdotal`
8. A bag has 50 red and 50 blue balls; I draw one unseen and ask you to make a market on red, then reveal new information and ask you to re-quote. `anecdotal`
9. What is the expected value of the sum of two six-sided dice, given that the sum is even? `anecdotal`
10. Describe a time you improved something proactively that no one asked you to. `general-prep/anecdotal`
