# Old Mission Capital — Round 2: Online Coding Assessment

**What this round assesses:** Algorithmic coding, data structures, basic simulation, and optimization under a time limit.

## Format

HackerRank is the most commonly reported platform; 2–3 algorithmic problems in about 60–90 minutes. `anecdotal`

## Online assessment details

Topics include stack/queue implementation, arrays/strings, graph traversal, and simulation or brute-force plus optimization. `anecdotal`

## Representative questions

1. Implement a data structure such as a stack or queue under specific constraints. `anecdotal`
2. Solve a string or array manipulation problem in the LeetCode-medium range. `anecdotal`
3. Solve a graph traversal problem. `anecdotal/general-prep`
4. Solve a basic simulation problem and then optimize the brute-force approach. `anecdotal`
