# Hudson River Trading — Interview Guide

Educational guide to Hudson River Trading's reported software-engineering interview process for automated trading systems roles.

## Snapshot

| Field | Details |
|---|---|
| Type | Automated quantitative trading firm (proprietary trading) |
| HQ | New York, New York, USA |
| Main offices | New York, Austin, Chicago, London, Singapore |
| Tech stack | C++, Python, high-performance networking and data infrastructure |
| C++ usage | Core language for systems-performance, Linux, infrastructure, and low-latency engineering roles. |
| Career page | https://www.hudsonrivertrading.com/careers/ |

## Compensation (public estimates)

These are public estimates from sources such as Glassdoor, levels.fyi, and Blind, not offers or official ranges.

| Level | Public estimate |
|---|---|
| Entry / mid | Entry/mid SWE reported around $180K–$250K base plus bonus. |
| Senior | Senior SWE reported around $250K–$350K+ base plus bonus; senior total compensation reported around $400K–$700K+, with some top IC reports higher. |

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---:|---|
| Recruiter / initial screen | 20–30 min | Fit, background, interest in automated trading systems, systems-engineering experience, and logistics. |
| Technical phone screen(s) | 1–2 rounds, 45–60 min | Live coding, algorithms, C++, Linux/systems depth, and occasionally a short OA/take-home beforehand. |
| Onsite / Final round | 4–5 interviews, often half-day | Software engineering, algorithms, system design, systems depth, and behavioral/culture fit. |
