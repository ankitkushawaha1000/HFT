# Point72 Asset Management (incl. Cubist Systematic Strategies) — Round 4: On-site — Coding Round 1 (Algorithms & Data Structures)

**What this round assesses:** Correct idiomatic C++ coding, complexity analysis, and edge-case discipline.

## Format

Live coding with one medium-hard problem and possible follow-up extension.

## Representative questions

1. Design a data structure supporting insert, delete, and getRandom in O(1). `anecdotal`
2. Maintain an in-memory order book from add/cancel/fill events and answer best bid/ask queries. `anecdotal`
3. Find all groups of anagrams in a list of strings. `anecdotal`
4. Implement a trie and use it to search for word prefixes. `anecdotal`
5. Word ladder: find minimum transformations between two words. `anecdotal`
6. Design a concurrent counter using std::atomic. `anecdotal`
