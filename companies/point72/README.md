## Interview process at a glance

| Round | Step | Typical length | What it assesses |
|---:|---|---|---|
| 1 | Recruiter Screen | ~30 min | Communication, motivation, and basic background plausibility. |
| 2 | Online Assessment (OA) | ~90 min | Algorithmic problem-solving speed and correctness. |
| 3 | Technical Phone Screen | 60 min | Live coding, communication while coding, and C++ core knowledge. |
| 4 | On-site — Coding Round 1 (Algorithms & Data Structures) | 45–60 min | Correct idiomatic C++ coding, complexity analysis, and edge-case discipline. |
| 5 | On-site — Coding Round 2 (Advanced or Domain-flavoured) | 45–60 min | Depth beyond typical LeetCode prep and translation of financial requirements into efficient code. |
| 6 | On-site — C++ / Systems Deep Dive | 45–60 min | Senior-level C++ and systems mastery for trading infrastructure. |
| 7 | On-site — System Design | 45–60 min | Architecture judgment, tradeoff defense, and production thinking. |
| 8 | Behavioral / Culture | 30–45 min | Collaboration, ownership, disagreement, failure handling, and motivation for systematic trading. |
