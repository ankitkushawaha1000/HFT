# Microsoft — Interview Guide (C++ / Systems focus)

Microsoft is a non-HFT high-comp employer with strong C++ usage in performance-sensitive systems, infrastructure, platforms, or product runtimes.

## Snapshot

| Field | Details |
|---|---|
| Type | Public (NASDAQ: MSFT) |
| HQ | Redmond, WA |
| Main offices | Bellevue, Seattle, NYC, San Francisco, Austin, Raleigh; London, Dublin, Hyderabad, Vancouver |
| Tech stack | Windows, Xbox SDK/runtime, DirectX/Direct3D, MSVC/STL, Visual Studio, Edge, WSL2, Azure C++ SDK, Bing, HoloLens/MR |
| C++ usage areas | Windows/kernel and user-mode systems, Xbox/DirectX, compiler/STL, Edge/Chromium, WSL, Azure SDK, game and mixed-reality systems |
| Career page | https://careers.microsoft.com/us/en/ |

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---|---|
| 1 | Recruiter Screen | 20–30 min phone/video non-technical screen |
| 2 | Technical Phone Screen / OA | OA/coding screen |
| 3 | Onsite — Coding / Algorithm | OA/coding screen |
| 4 | Onsite — System Design | 45–60 min virtual whiteboard/doc round, usually L63+; practical OOP or distributed-systems prompts |
| 5 | Hiring Manager / Behavioral | 45–60 min conversational no-coding round with hiring manager |
