# Microsoft — Round 2: Technical Phone Screen / OA

**What this round assesses:** Basic algorithm/DS competency and ability to write clean code while communicating.

## Format

Live 45-min coding call via CoderPad or Microsoft interview tooling; some campus pipelines use HireVue or CodeSignal.

## Online assessment details

Platform: CoderPad or internal tool for experienced hires; HireVue or CodeSignal for some campus/new-grad pipelines. Number/type: 1–2 coding problems. Representative topics: linked lists, trees, two-sum, stacks/queues. `anecdotal`

## Representative questions

1. Reverse a linked list iteratively and recursively; follow-up: reverse in groups of K. `anecdotal`
2. Check whether a tree is a valid binary search tree. `anecdotal`
3. Two-sum with sorted array. `anecdotal`
4. Implement a stack using two queues. `anecdotal`
