# Amazon — Interview Guide (C++ / Systems focus)

Amazon is a non-HFT high-comp employer with strong C++ usage in performance-sensitive systems, infrastructure, platforms, or product runtimes.

## Snapshot

| Field | Details |
|---|---|
| Type | Public (NASDAQ: AMZN) |
| HQ | Seattle, WA; HQ2 Arlington, VA |
| Main offices | NYC, Austin, Boston, Berlin, Dublin, Luxembourg, London, Vancouver, Bangalore; AWS offices globally |
| Tech stack | AWS Nitro, Kindle firmware, Alexa, Amazon Robotics, Zoox, Amazon Games, Prime Video, Aurora, Graviton/Trainium/Inferentia runtimes, Kuiper |
| C++ usage areas | AWS hypervisor/runtime systems, firmware, robotics, autonomous vehicles, games, video encoding, storage engines, custom silicon drivers |
| Career page | https://www.amazon.jobs/ |

## Compensation (public estimates)

| Level | Title | Public-estimate TC range (Year 3–4) |

| L4 | SDE I | $185k – $235k |
| L5 | SDE II | $245k – $340k |

Public estimates from levels.fyi user reports; these are not offers. Amazon RSU vesting is backloaded, so year 1–2 and year 3–4 realized TC can differ materially. Source: https://www.levels.fyi/companies/amazon/salaries/software-development-engineer/ `anecdotal`

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---|---|
| 1 | Online Assessment (OA) on HackerRank | OA/coding screen |
| 2 | Phone Screen | OA/coding screen |
| 3 | Onsite Loop — Coding / Algorithm | OA/coding screen |
| 4 | Onsite — System Design | 45–60 min virtual whiteboard round for SDE II+; Bar Raiser may attend |
| 5 | Bar Raiser Round | 45–60 min with a trained cross-team Bar Raiser; may include coding, LP questions, or light design discussion |
