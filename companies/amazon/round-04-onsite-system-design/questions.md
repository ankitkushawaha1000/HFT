# Amazon — Round 4: Onsite — System Design

**What this round assesses:** Distributed systems design, scalability, AWS/product knowledge, API design, and LP reasoning through design decisions.

## Format

45–60 min virtual whiteboard round for SDE II+; Bar Raiser may attend.

## Representative questions

1. Design Amazon S3 — object storage, multipart upload, eventual consistency, versioning, metadata service. `anecdotal`
2. Design Amazon's Product Recommendation System — collaborative filtering, realtime personalization, A/B testing. `anecdotal`
3. Design a Distributed Message Queue like SQS — durability, at-least-once delivery, consumer groups, dead-letter queues. `anecdotal`
4. Design Amazon's Order Management System — lifecycle, inventory, payment, delivery tracking. `anecdotal`
5. Design a Ride-Sharing App — location tracking, matching, trip lifecycle. `anecdotal`
6. Design a Notification Service — push/SMS/email fan-out, rate limits, delivery guarantees, deduplication. `anecdotal`
7. Design Amazon Prime Video — ingestion, transcoding, adaptive bitrate streaming, global CDN. `anecdotal`
8. Design Alexa — ASR pipeline, intent recognition, skill routing, edge vs. cloud. `anecdotal`
