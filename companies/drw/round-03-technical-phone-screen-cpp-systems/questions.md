# DRW — Round 3: Technical Phone Screen 2

**What this round assesses:** Deep C++, Linux systems, concurrency, memory, networking, and performance concepts.

## Format

60-minute technical screen focused on C++ and Linux systems questions.

## Representative questions

1. "Explain the difference between a process and a thread. How does the Linux kernel schedule threads?" `anecdotal`
2. "What is a spinlock vs. a mutex? In what scenarios would you prefer a spinlock, and what are its pitfalls?" `anecdotal`
3. "What are C++ memory orderings? Explain `acquire`/`release` semantics and why `seq_cst` has a performance cost." `anecdotal`
4. "How does `mmap` work? When would you use it instead of `malloc`?" `anecdotal`
5. "What is `epoll` and how does it differ from `select`/`poll`? Why is it critical for high-performance networking?" `anecdotal`
6. "Explain copy elision and Return Value Optimization (RVO/NRVO)." `anecdotal`
7. "What is `[[likely]]` / `[[unlikely]]` in C++20 and how does it guide compiler optimization?" `anecdotal`
8. "What are C++ coroutines (C++20)? How do they differ from OS threads and when would you use them?" `anecdotal`
