# DRW — Round 2: Technical Phone Screen 1

**What this round assesses:** Algorithmic coding, data structures, and domain-flavored problem solving.

## Format

60-minute coding screen on HackerRank or CoderPad, varying by team. Usually 1–2 LeetCode medium-to-hard style problems.

## Representative questions

1. "Implement a least-recently-used (LRU) cache with O(1) get and put." `anecdotal`
2. "Given a stream of trade events (symbol, side, quantity, price), implement a function returning the current VWAP for each symbol." `anecdotal`
3. "Find the shortest path between two nodes in a weighted directed graph. Handle negative edges." `anecdotal`
4. "Implement a function to check if a BST is valid." `anecdotal`
5. "Design an algorithm to merge K sorted linked lists." `anecdotal`
6. "Given a matrix, find the number of distinct islands (connected components of 1s)." `anecdotal`
