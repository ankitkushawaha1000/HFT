# Two Sigma — Round 2: Online Assessment

**What this round assesses:** Algorithmic problem solving, coding fluency, and standard data-structure knowledge.

## Format

HackerRank assessment with 2–3 algorithmic coding problems in a 90-minute window. Reports describe LeetCode medium-to-hard difficulty; language choice is generally flexible.

## Online assessment details

- **Platform:** HackerRank.
- **Problems:** 2–3 coding problems, often including one easier array/string warm-up and one DP or graph problem.
- **Representative OA topics:** Sliding window/two pointers, dynamic programming, BFS/DFS on grids, interval merging, and event-order simulations.

## Representative questions

1. Sliding window / two-pointer problem, e.g. a "longest substring without repeating characters"-style task. `anecdotal`
2. Dynamic programming: "Count number of ways to decode a string" similar to LC 91. `anecdotal`
3. BFS/DFS on a grid or matrix. `anecdotal`
4. Interval merging or meeting rooms. `anecdotal`
