# Two Sigma — Interview Guide

Educational prep guide for publicly reported Two Sigma software engineering interviews.

## Snapshot

| Field | Details |
|---|---|
| Type | Quantitative hedge fund + systematic trading firm |
| HQ | New York City (Hudson Square) |
| Main offices | Houston, London, Hong Kong, Tokyo, Seattle |
| Tech stack | Python, C++, Java/Scala, Julia, proprietary distributed compute frameworks, Linux |
| C++ usage | Latency-sensitive execution systems, market-data handlers, order routing, risk engines, real-time tick processing, co-location systems |
| Career page | https://www.twosigma.com/careers/ |

## Compensation (public estimates)

Public estimates are not offers and can vary by year, level, location, team, and bonus outcomes. Entry-level SWE estimates are about **$220K–$280K total compensation**. Senior L5+ estimates are about **$500K–$800K+ total compensation**, with highly variable bonuses.

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---:|---|
| Recruiter screen | 30 min | Background, motivation, logistics, role fit |
| Online assessment | 90 min | Data structures, algorithms, coding speed |
| Technical phone screen | 60 min | Live coding, CS fundamentals, C++/systems basics |
| Onsite / virtual onsite | 4–5 hours | Algorithms, C++ systems, system design, probability/statistics, behavioral fit |
