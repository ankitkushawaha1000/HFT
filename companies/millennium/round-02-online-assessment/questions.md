# Millennium Management — Round 2: Online Assessment (OA)

**What this round assesses:** Correctness and efficiency of algorithmic solutions under time pressure.

## Format

Unproctored timed HackerRank coding challenge with 2–3 algorithmic problems.

## Online assessment details

Platform: HackerRank (anecdotal). Problems: 2–3. Duration: ~90 minutes. Difficulty: LeetCode medium to medium-hard. Common topics include sliding windows, dynamic programming, graph traversal, string parsing, and hash maps.

## Representative questions

1. Find the maximum subarray sum, using a Kadane-style variant. `anecdotal`
2. Given stock prices, find maximum profit with at most K buy-sell transactions. `anecdotal`
3. Find the shortest path in a grid with blocked cells. `anecdotal`
4. Implement a function to check whether a string is a valid floating-point number. `anecdotal`
