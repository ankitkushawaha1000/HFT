# Millennium Management — Round 4: On-site — Coding / Algorithms

**What this round assesses:** Problem decomposition, clean implementation, complexity reasoning, and edge-case handling.

## Format

Live coding session with one medium-hard problem and follow-up variants.

## Representative questions

1. Design and implement a thread-safe bounded queue in C++ using a mutex and condition variables. `anecdotal`
2. Given a stream of market ticks, compute a rolling average over the last N events. `anecdotal`
3. Find the k-th largest element in a data stream supporting online inserts. `anecdotal`
4. Find the lowest common ancestor of two binary-tree nodes. `anecdotal`
5. Merge K sorted linked lists into one sorted list. `anecdotal`
6. Merge overlapping time intervals. `anecdotal`
7. Implement a fixed-capacity circular buffer/ring buffer in C++. `anecdotal`
