# Squarepoint Capital — Round 5: On-site — Algorithms and Data Structures

**What this round assesses:** Algorithmic implementation depth, complexity analysis, and C++ data-structure design.

## Format

Live coding with one harder algorithmic problem and follow-up discussion.

## Representative questions

1. Implement a skip list with O(log n) expected insert, delete, and search. `anecdotal`
2. Given real-time ticks, return the median price using two heaps and handle removals. `anecdotal`
3. Implement Dijkstra's algorithm and discuss complexity with different priority queues. `anecdotal`
4. Merge N sorted arrays of varying length using minimum comparisons. `anecdotal`
5. Implement a concurrent hash map using bucket-level locking in C++. `anecdotal`
