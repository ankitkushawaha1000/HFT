# Google — Round 2: Technical Phone Screen

**What this round assesses:** Coding fluency, problem-solving approach, tradeoff discussion, and code quality under time pressure.

## Format

Video call (~45 min), shared Google Doc, 1–2 algorithm problems; Google Docs is plain text with no autocomplete.

## Online assessment details

Platform: Google Meet + Google Docs. Number/type: 1–2 live algorithm problems. Representative topics: arrays, sliding window, binary search, graph BFS/DFS, trees, and light DP. `official`

## Representative questions

1. Array two-pointer or sliding-window problem, such as longest substring without repeating characters. `anecdotal`
2. Binary search on a sorted rotated array. `anecdotal`
3. Graph BFS/DFS, such as number of islands or word ladder. `anecdotal`
4. Tree traversal, such as serialize/deserialize binary tree. `anecdotal`
5. Simple dynamic programming warm-up. `anecdotal`
6. In C++, choose clear STL containers and explain complexity rather than relying on language tricks. `inferred`
