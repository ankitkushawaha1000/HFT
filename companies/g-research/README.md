## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---|---|
| 1. Aptitude / Psychometric Test | 45–75 minutes | Cognitive ability, numerical speed, logical reasoning, and abstract pattern recognition. |
| 2. Coding Test | 60–120 minutes | Algorithmic problem-solving, data structures, code correctness, and C++ or Python implementation ability. |
| 3. Technical Interview (C++ / Systems / Mathematics) | 45–60 minutes | Production C++ expertise, systems understanding, mathematical rigour, and probabilistic reasoning. |
| 4. Advanced Technical / Research Interview | 60–90 minutes | Expert-level engineering depth, performance diagnosis, distributed/system design, statistical modelling, and research methodology. |
| 5. Final Round (Hiring Manager + Behavioural) | 45–60 minutes | Long-term fit, intellectual curiosity, collaboration, ownership, and motivation for quant research. |
