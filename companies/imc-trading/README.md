# IMC Trading — Interview Guide

Educational prep guide for publicly reported IMC Trading software engineering interviews.

## Snapshot

| Field | Details |
|---|---|
| Type | Proprietary trading firm and global market maker in equities, options, bonds, and ETFs |
| HQ | Amsterdam, Netherlands |
| Main offices | Chicago, Sydney, Hong Kong |
| Tech stack | C++, Python, Java, FPGA, Linux RHEL/CentOS, DPDK/kernel-bypass networking |
| C++ usage | Order book management, exchange connectivity, market-making algorithms, co-location infrastructure, zero-cost abstractions, compile-time optimization |
| Career page | https://www.imc.com/us/careers/ |

## Compensation (public estimates)

Public estimates are not offers and can vary by year, level, location, team, and bonus outcomes. Entry-level Chicago SWE estimates are about **$180K–$260K total compensation**. Senior estimates are about **$450K–$700K+ total compensation**, with discretionary bonus variation.

## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---:|---|
| Recruiter screen | 30 min | Background, role fit, motivation, logistics |
| Online assessment | 60–90 min | Algorithms, data structures, coding speed, simulation |
| Technical phone screens | 45–60 min each | Algorithms/DS and C++ systems knowledge |
| Onsite / virtual onsite | 4–5 hours | Advanced coding, C++ systems, market-making game, probability, behavioral fit |
