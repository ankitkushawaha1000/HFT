# IMC Trading — Round 2: Online Assessment

**What this round assesses:** Coding fluency, algorithms, data structures, and simulation-style reasoning.

## Format

HackerRank assessment with 2–3 problems over 60–90 minutes. Reports describe LeetCode-medium difficulty and occasional trading/order-book-style simulation.

## Online assessment details

- **Platform:** HackerRank.
- **Problems:** 2–3 coding problems.
- **Representative OA topics:** Prefix sums, binary search on answer, graph traversal, string parsing/simulation, simplified order matching.

## Representative questions

1. Array manipulation / prefix sums. `anecdotal`
2. Binary search on answer, e.g. "minimum time to complete tasks." `anecdotal`
3. Graph traversal or BFS/DFS problem. `anecdotal`
4. String parsing / simulation problem, e.g. implementing a simplified command parser. `anecdotal`
5. "Implement a simplified order matching engine" — match buy/sell orders by price-time priority. `anecdotal`
