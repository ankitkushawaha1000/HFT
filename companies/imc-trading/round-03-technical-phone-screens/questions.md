# IMC Trading — Round 3: Technical Phone Screens

**What this round assesses:** Algorithms/data structures in one screen and C++/systems fluency in another.

## Format

Two separate 45–60 minute live coding rounds via CoderPad or similar. One is typically algorithms/DS; one is C++-focused.

## Representative questions

1. "Implement a min-heap from scratch. Now use it to find the K closest points to the origin." `anecdotal`
2. "Given an array of stock prices, find the maximum profit from at most K transactions." `anecdotal`
3. "Implement a trie and use it for autocomplete." `anecdotal`
4. "Design an algorithm to find the longest palindromic substring." `anecdotal`
5. "You are given a log file with timestamps. Find all events that occur within 5 minutes of each other." `anecdotal`
6. "What is the difference between `std::vector` and `std::deque`? When would you prefer each, and what are the memory layout implications?" `anecdotal`
7. "Explain template specialization vs. template overloading. Give an example where you'd use full specialization." `anecdotal`
8. "What is CRTP (Curiously Recurring Template Pattern) and what problem does it solve vs. virtual dispatch?" `anecdotal`
9. "Write a `constexpr` function that checks if a number is prime at compile time." `anondotal`
10. "What is cache coherence? Explain MESI protocol at a high level and how it affects multi-threaded C++ programs." `anecdotal`
11. "What is `std::memory_order_acquire` / `release` semantics? Write a simple spinlock using `std::atomic_flag`." `anecdotal`
12. "Explain the performance implications of branch misprediction and how to write branch-predictor-friendly code." `anecdotal`
