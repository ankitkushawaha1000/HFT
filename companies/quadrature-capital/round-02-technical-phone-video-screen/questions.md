# Quadrature Capital — Round 2: Technical Phone/Video Screen

**What this round assesses:** Coding skill, algorithmic explanation, Python/C++ fundamentals, systems basics, and communication.

## Format

~45–60 minutes with one interviewer, mixing coding and technical discussion. `anecdotal`

## Representative questions

1. Implement quicksort and discuss worst-case time complexity and mitigation. `anecdotal/general-prep`
2. Given a sorted array rotated at an unknown pivot, find a target value. `anecdotal`
3. What is the difference between a process and a thread, and when would you use each? `anecdotal/general-prep`
4. Explain how Python’s GIL affects multithreaded performance. `inferred`
5. What is a race condition? Describe one you have encountered or could construct. `general-prep`
