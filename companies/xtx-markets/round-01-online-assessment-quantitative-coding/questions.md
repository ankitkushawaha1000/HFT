# XTX Markets — Round 1: Online Assessment (Quantitative / Coding)

**What this round assesses:** Algorithmic coding, quantitative reasoning, data analysis, and statistical thinking.

## Format

Timed coding and quantitative/statistical assessment with a stronger ML/statistics flavour than classic HFT OAs.

## Online assessment details

Platform: proprietary or HackerRank. Number/type: coding problems plus quantitative/statistical reasoning. Representative topics: dynamic programming or graph search, rolling statistics, simple ML implementation, and Bayesian probability.

## Representative questions

1. Algorithmic problem requiring dynamic programming or graph search at medium-hard LeetCode level `anecdotal`
2. Given a stream of prices, implement an online algorithm for rolling mean and variance efficiently. `inferred`
3. Implement a basic logistic regression from scratch in Python/C++ and evaluate it on a sample dataset. `inferred`
4. You observe 10 coin flips: 7 heads and 3 tails. Estimate the probability the coin is fair vs biased using Bayesian inference. `inferred`
