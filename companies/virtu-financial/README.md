## Interview process at a glance

| Round | Typical length | What it assesses |
|---|---|---|
| 1. Online Assessment (Probability / Coding) | 60–90 minutes | Basic DSA fluency, EV reasoning, and market-making intuition. |
| 2. Technical Phone Screen / Interview (Market Making + Systems) | 45–60 minutes | C++ proficiency, low-latency data pipelines, order books, FIX, and market microstructure. |
| 3. Quoting Simulation / Inventory Management | 30–60 minutes | Real-time EV, risk management, quote adjustment with inventory, and adverse-selection awareness. |
| 4. Final Round (Behavioural + System Design) | 45–60 minutes | Production systems judgment, ownership, communication, and senior-level technical trade-offs. |
